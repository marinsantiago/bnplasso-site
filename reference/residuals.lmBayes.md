# Residuals from an object of class `lmBayes`

Extracts the posterior predictive residuals from an object of class
`lmBayes`.

## Usage

``` r
# S3 method for class 'lmBayes'
residuals(object, ...)
```

## Arguments

- object:

  An object of class `'lmBayes'`.

- ...:

  Further arguments passed to.

## Value

A data.frame with summary statistics of the posterior predictive
distribution of the model residuals.
