# Regression coefficients

Extracts the posterior distribution of the regression coefficients from
an object of class `lmBayes`.

## Usage

``` r
# S3 method for class 'lmBayes'
coef(object, ...)
```

## Arguments

- object:

  An object of class `'lmBayes'`.

- ...:

  Further arguments passed to.

## Value

A data.frame with summary statistics of the posterior distribution of
the regression coefficients.
