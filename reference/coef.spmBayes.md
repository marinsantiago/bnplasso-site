# Mean parameters

Extracts the posterior distribution of the mean parameters from an
object of class `spmBayes`.

## Usage

``` r
# S3 method for class 'spmBayes'
coef(object, ...)
```

## Arguments

- object:

  An object of class `'spmBayes'`.

- ...:

  Further arguments passed to.

## Value

A data.frame with summary statistics of the posterior distribution of
the mean parameters.
