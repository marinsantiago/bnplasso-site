# Fitted values

Extracts the posterior predictive fitted values from an object of class
`spmBayes`.

## Usage

``` r
# S3 method for class 'spmBayes'
fitted(object, ...)
```

## Arguments

- object:

  An object of class `'spmBayes'`.

- ...:

  Further arguments passed to.

## Value

A data.frame with summary statistics of the posterior predictive fitted
values.
